# 🌟 Overview

**MediSpace AI** is a modern healthcare web application that simplifies the way users manage their medical information.

Instead of carrying paper prescriptions and reports, users can securely organize their healthcare documents, extract text using AI-powered OCR, and instantly locate nearby hospitals and specialists—all within a sleek glassmorphism dashboard.

---

# ✨ Features

### 🩺 Health Vault
- Store medical reports digitally
- Organize prescriptions securely
- Easy access anytime

### 📄 AI OCR Report Scanner
- Upload prescriptions
- Extract text automatically
- View digitized medical information

### 🏥 Hospital & Doctor Finder
- Interactive map interface
- Locate nearby hospitals
- Search healthcare specialists

### 🎨 Modern Dashboard
- Glassmorphism UI
- Smooth animations
- Responsive on all devices
- Beautiful gradients and transitions

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/akshayraj06/MediSpace.git
```

```bash
cd MediSpace
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
